# 特殊染色タイマー / Special Stain Timer

病理検査における特殊染色の反応時間を管理するための、ブラウザベースのタイマーアプリです。
インストール不要で、PC・タブレット・スマートフォンのブラウザから使用できます。

## 特徴

- **7種類の主要な特殊染色プリセット** を内蔵
- **複数のタイマーを並行して運用** 可能（ダッシュボード形式）
- **カスタム染色の追加・編集・削除** 機能
- **プリセットの編集と初期値リセット** 機能（施設ごとのプロトコルに合わせられます）
- **ステップごとの自動カウントダウン** とアラーム音
- **オフラインで動作** — インターネット接続不要
- **データは全てブラウザ内に保存** — サーバー送信は一切なし

## 対応プリセット染色

| 染色名 | 英語名 |
|--------|--------|
| PAS染色 | Periodic Acid-Schiff |
| マッソントリクローム染色 | Masson's Trichrome |
| EVG染色 | Elastica van Gieson |
| PAM染色 | Periodic Acid Methenamine Silver |
| アザン染色 | Azan stain |
| コンゴーレッド染色 | Congo Red |
| ベルリンブルー染色 | Berlin Blue (Prussian Blue) |

各プリセットは画面上で自由に編集でき、変更内容は端末内に保存されます。
「初期値に戻す」ボタンでいつでも元のプロトコルに戻せます。

## 使い方

1. ブラウザでアプリを開きます
2. 使いたい染色をタップしてタイマーを開始します
3. 「開始」ボタンを押すとカウントダウンが始まります
4. ステップが終わるとアラーム音と画面フラッシュで通知されます
5. 自動で次のステップに進みます

複数の染色を同時に走らせたい場合は、ヘッダーの「＋ 追加」または「実行中」ボタンから別の染色を追加できます。

## インストール不要

公開URLにブラウザでアクセスするだけで使えます。
PWA（Progressive Web App）に対応しているため、スマートフォンのホーム画面に追加すれば**ネイティブアプリのように使えます**。

### Android

1. Chromeでアプリを開く
2. 自動で表示される「ホーム画面に追加」バナーをタップ
3. または メニュー（︙）→「ホーム画面に追加」

### iOS (iPhone / iPad)

1. Safariでアプリを開く
2. 共有ボタン（↑）をタップ
3. 「ホーム画面に追加」を選択

ホーム画面から起動すると、ブラウザのアドレスバーが非表示のスタンドアロンモードで動作します。オフラインでも使えます。

## ネイティブアプリとしてストア公開する場合

Google Play や App Store に公開したい場合は、[Capacitor](https://capacitorjs.com/) を使ってネイティブアプリにラップできます。

### 必要な環境

- **共通**: Node.js 18+
- **Android**: Android Studio, JDK 17+
- **iOS**: macOS, Xcode 15+, CocoaPods（Mac必須）

### 手順

```bash
# プロジェクトディレクトリで実行
npm init -y
npm install @capacitor/core @capacitor/cli

# Capacitor初期化（パッケージ名は適宜変更）
npx cap init "特殊染色タイマー" "com.example.stainstimer" --web-dir .

# プラットフォーム追加
npx cap add android    # Android用
npx cap add ios        # iOS用（Mac必須）

# Webファイルを同期
npx cap sync

# IDE で開いてビルド・リリース
npx cap open android   # → Android Studio
npx cap open ios       # → Xcode
```

### ストア公開に必要なもの

| ストア | 費用 | 備考 |

| Google Play | $25（一回払い） | 開発者アカウント登録、署名済みAABファイル |

## エクスポート / インポート

染色選択画面下部の「データ管理」セクションから、染色プロトコルのバックアップと復元ができます。

### エクスポート (JSON)

「エクスポート (JSON)」ボタンをタップすると、カスタム染色とプリセットの編集内容を含むJSONファイルがダウンロードされます。バックアップや他の端末への移行に使えます。

### インポート

以下の3形式に対応しています：

| 形式 | 説明 |
|------|------|
| **JSON** | エクスポートしたファイル、または染色データの配列 |
| **CSV** | カンマ区切りまたはタブ区切りのテキストファイル |
| **Excel (.xlsx)** | Excelブック（最初のシートを読み込み） |

#### CSV / Excel のフォーマット

ヘッダー行に以下のいずれかの列名を含めてください：

| 列名（いずれかに一致） | 内容 | 必須 |
|----------------------|------|------|
| 染色名, stain | 染色の名前（同じ名前のステップがグループ化されます） | 推奨 |
| ステップ名, step | ステップの名前 | **必須** |
| 時間, 分, duration, min | 時間（分単位、または `分:秒` 形式） | 推奨 |
| メモ, note, 備考 | 補足メモ | 任意 |
| 英語名, english | 染色の英語名 | 任意 |

例:

```
染色名,ステップ名,時間(分),メモ
ギムザ染色,ギムザ液,30,
ギムザ染色,水洗,1,流水
```

> **注意:** Excelインポートにはインターネット接続が必要です（初回のみライブラリを読み込みます）。JSON・CSVインポートはオフラインでも動作します。

## データの取り扱い

このアプリは **完全にクライアントサイドで動作** します。

- 編集したプロトコル・カスタム染色は **ブラウザの localStorage** に保存されます
- 外部サーバーへのデータ送信は **一切ありません**
- アクセス解析やCookieも使用していません
- データは使用しているブラウザの中だけに残り、別の端末・別ブラウザとは共有されません
